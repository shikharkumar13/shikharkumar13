## 👋 About me

I'm an ML engineer who spends as much time on what happens *after* `model.fit()` as before it: reproducible feature pipelines, experiment tracking, containerised APIs and monitoring for drift. Before focusing on MLOps I trained **20,000+ working professionals and freshers** in data science, which taught me to build things other people can actually understand and maintain.

- 🔭 **Building:** WealthPath, a goal-based investment planner with ML risk profiling and an LLM explanation layer
- 🚀 **Shipped:** a credit-risk model on LendingClub loan data, served with FastAPI + Docker, with monitoring
- 📚 **Teaching:** free, code-verified courses in Python, statistics, feature engineering and GenAI (catalog below)
- 🎯 **Looking for:** remote **ML Engineer / MLOps Engineer** roles
- 📍 New Delhi, India · 🎓 Post Graduate in AI
